# BỘ TEST CASE HỢP NHẤT HỆ THỐNG EASYMALL (v3.0)

**Phạm vi:** Chỉ gồm các module chính phục vụ báo cáo Chương 4 — đã lược bỏ Đánh giá sản phẩm, Quản lý địa chỉ, Upload File so với bản v2.0 (hợp nhất đầy đủ).

**Nguồn dữ liệu:** Rà soát mã nguồn Backend/Frontend (135 TC gốc) + bổ sung từ `chuong4_testcase.md` (16 TC mới, đã loại trùng).

**Cột Kết quả thực tế / Trạng thái:** để trống — điền sau khi chạy test thật (thủ công hoặc qua Postman Collection đã cung cấp), không điền sẵn để đảm bảo tính trung thực số liệu thực nghiệm.
